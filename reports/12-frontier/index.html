副标题：统一模型、推理训练与世界模型的三个技术问题 版本日期：2026-10-16 | 先修：第 05、06、09、10、11 章

摘要

“统一理解与生成”“推理增强”“世界模型”指向不同的建模和验证问题，不能用一张时间线证明它们正在解决同一个瓶颈。本章选取已核对的原始论文作为机制案例，分别写出可实施的对照实验：共享参数是否带来正迁移，奖励优化是否增加视觉依赖，观测预测是否足以支持动作规划。这里的“前沿”指仍未由现有证据解决的问题，不是对 2026 年所有新发布结果的完整排行榜；未检索和核验的项目不作为事实补进来。

1. 统一到底统一了什么

Chameleon [1] 将文本与量化图像放入混合离散序列；Transfusion [2] 把文字 next-token 目标与连续图像去噪目标放进共享 Transformer。两者都称统一，但表示、损失和 attention 约束不同，因此不能只按“一个模型/两个模型”分类。

对共享参数 \(\theta_s\)，一个混合目标可以抽象为：

\[ \mathcal L=\lambda_{txt}\mathbb E\mathcal L_{CE}+\lambda_{img}\mathbb E\mathcal L_{denoise}. \]

两个 loss 的绝对量纲、有效位置数、时间步权重和采样比例不一样，系数相同不代表梯度贡献相同。可以检查共享层两类梯度的范数与夹角 \(\langle g_t,g_i\rangle/(\|g_t\|\|g_i\|)\)；负夹角只表示当前 minibatch、当前参数处的一阶冲突，不自动预测最终负迁移。

表示也会限制结论。Chameleon 的图像 tokenizer 将 512×512 图像编码为 1024 个离散码，论文明确讨论了密集文字重建的弱点 [1, 2.1 节]。生成器若没有保留小字信息，扩大语言模型不能从丢掉的码里恢复原始文字。连续 latent 路线同样需要检查 autoencoder 的重建上界。

1.1 实验 A：共享训练是否真的产生正迁移

建立三组：独立理解模型与生成模型；共享 backbone 的混合目标；同一共享模型但固定一种模态的训练流。预先指定总参数、总训练计算、数据曝光和推理预算分别怎样匹配，因为“参数匹配”和“训练计算匹配”不一定能同时完美成立。

理解侧评估需要视觉证据的任务、OCR 与细粒度关系；生成侧评估质量、提示遵循和覆盖。主结果呈现质量—训练计算—推理开销的 Pareto 关系，而不把不同指标压成一个任意加权总分。同步记录单模态基线的变化，检验混合训练是否让某一类能力退化。

证伪条件也要事先写清：如果共享模型只在额外图文数据下获益、固定数据后没有增益，那么原主张应改成数据收益；如果在相同部署预算下只改善一侧，应报告任务相关的取舍，而不是笼统称“统一更优”。

1.2 一个可以先做的小规模实例

下面是尚待执行的最小研究配置，数字是预先选择的实验参数，绝非论文结果。先将问题缩小为带精确属性标签的程序生成场景，避免还没弄清梯度共享就引入不可控制的互联网数据。

图像为 64×64 RGB，由圆、方形与三角形组成，位置、颜色、尺寸由离散参数决定。将图像分成 4×4 像素 patch，得到 256 个 48 维连续向量；文字使用固定 byte 词表和不超过 32 个位置的结构化描述。理解任务读图后输出属性，生成任务根据包含完整位置、颜色与尺寸的描述重建图像。此时可以用属性准确率和归一化像素误差检查最基本的跨任务干扰；它还不是自然图像理解与生成的替代评测。

先取 8 层、隐藏维 256、8 heads、普通 MLP 宽度 1024 的 Transformer。共享组用同一 backbone 加文字与 patch 输出头；独立组用两套同规格 backbone。图像内部允许双向注意力，回答文字按 causal mask 读取图像与过去文字；去噪目标的时间条件与文字条件必须单独记录。两组主比较匹配总训练 FLOPs，独立组的两个任务各分一半预算；另列参数容量与推理开销，避免同时声称参数和计算都匹配。

预定预算为每组 \(10^{16}\) 个计数 FLOPs，按实际 batch 的投影、MLP 与 attention 操作累计；不按相同步数冒充相同计算。90,000/5,000/5,000 个场景分别用于训练、开发和测试，同一渲染模板及其属性变体进入同一族；另留若干未见颜色—形状组合。用 seeds 11、22、33 重复。开发集只用来检查优化与选择一次固定 loss 权重；最后报告完整学习曲线与独立 seed 的结果。

每个训练 checkpoint 同时测两项任务，记录各 loss、共享层梯度范数与夹角、累计 FLOPs、有效目标数和样本曝光。只有在固定数据和主资源约束下，两侧质量均不退化且至少一侧改善，才能称为该配置上的正迁移。若只在额外参数或数据条件下占优，结论必须带上相应条件。这个小实验的用途是排除明显的混杂，再决定是否值得扩展到论文级模型。

2. 推理 token 变多，视觉证据会不会反而减少

DeepSeek-R1 [3] 为基于奖励的推理训练提供了原始案例，但其文本推理结果不能直接证明多模态 grounding 随推理长度增长。对图像问题，模型可能在长推理中反复放大一个错误的初始视觉判断，也可能通过逐步检查纠正它，需要真实对照。

最终答案的可验证性与视觉必要性是两个不同条件。一个数学问题若文字已包含所有量，正确奖励不会迫使策略使用图片。反之，一道必须看图的题，如果 verifier 只检查固定格式，也可能允许 reward hacking。

2.1 实验 B：奖励是否增强了视觉条件依赖

构造专家复核的成对输入：同一文字问题，图像只改变一个决定答案的属性，并给出两份正确答案。先测未训练模型、SFT、偏好训练或 RL 后的策略；训练数据、初始 checkpoint 和额外计算分别记录。对每组同时评估正确图准确率、错图敏感性、答案翻转正确率、拒答和推理长度。

对照中至少包含文字独立可解题与视觉必要题。若两类题都提高，收益可能是语言推理或格式改善；只有反事实属性变化被正确追踪，才提供视觉依赖增强的证据。单纯“换图后答案变了”也不够，因为随机不稳定同样会改变答案。

推理预算需要按实际输出 token、采样次数和 verifier 调用计量。比较一个策略的单次回答与另一个策略的多次选择，不应称为同预算模型能力对照。记录失败轨迹，特别检查在第一个视觉事实处已经出错却继续自洽推演的案例。

2.2 先区分 checkpoint 比较与训练方法比较

最小冒烟测试可只做 32 对手工核验的反事实图像；正式测试再冻结至少 500 个图像族。每对保持问题模板一致，改变唯一决定答案的属性，如物体颜色；两个图都要回答正确，才算 pair-both-correct：

\[ \mathrm{PBC}=\frac{1}{N}\sum_{i=1}^{N}\mathbf 1[\hat y_i=y_i\ \land\ \hat y'_i=y'_i]. \]

同时报仅文字输入、正确图、错图和无关背景替换。固定允许答案集合、大小写规则与无效输出处理；按图像族而非单图划分训练、开发与测试。PBC 比“答案是否变化”更严格：随机翻转不会获得信用。

第一阶段若只有现成 checkpoint，就只比较 checkpoint，记录模型规模、训练来源、访问日期与相同的评测输出预算，不能将差异归因到 GRPO 或 DPO。第二阶段才能从同一初始化分叉训练。例如选 BLIP-2 的 OPT-2.7B 桥接配置，冻结视觉塔与 LLM，仅更新 Q-Former/投影；先用已核验的 2,000 个图像族构造同一份训练池，分别建立 SFT 正确答案、DPO 正负答案和程序可判定奖励。执行前固定真实 checkpoint revision、tokenizer 和图像预处理。

三组以相同总训练 FLOPs 为主预算，另记 rollout token、参考模型、核验器与优化计算。RL 每题采 4 个回答，奖励只由冻结答案谓词给出；全同奖励组单独统计。加入图像在 batch 内随机置换、保持文字与更新模块不变的负对照，检查收益是否绕过视觉。每组至少 3 个 seed，在相同解码长度与相同候选数下测 PBC、正确图准确率、拒答和延迟。这个配置主要检验属性 grounding；不能直接外推长链几何推理或开放世界事实性。

3. 世界模型为什么需要动作干预

令编码为 \(z_t=e(o_t)\)，动作条件预测为 \(\hat z_{t+1}=f_\theta(z_{\leq t},a_t)\)。给定目标表示 \(z_g\)，一个简化 planning 目标为：

\[ \min_{a_{t:t+H-1}}\sum_{k=1}^{H}c(\hat z_{t+k},z_g)+\lambda\sum_{k=0}^{H-1}\|a_{t+k}\|^2, \qquad \hat z_{t+k+1}=f_\theta(\hat z_{\leq t+k},a_{t+k}). \]

预测误差、表示距离与真实任务代价并不相同。规划器会主动寻找低预测代价的动作，恰好可能利用模型在训练分布之外的漏洞；因此不能只用随机测试轨迹上的平均预测误差评价 planning。

V-JEPA 2 [4] 区分大规模无动作视频预训练与后续动作条件模型 V-JEPA 2-AC。原文所说约 62 小时“unlabeled”交互视频并不是完全没有控制信息：仍包含末端状态等信号，只是不使用任务、奖励或成功标签 [4, 3.1 节]。这是影响方法可复现性的关键条件。

3.1 观测相关不是动作效应

设构造系统 \(y=0.2a+0.8c+\epsilon\)，其中 \(c\) 是背景条件。如果历史策略倾向在 \(c\) 大时采取大动作，那么 \(a\) 与 \(c\) 相关，直接回归 \(y\) 对 \(a\) 会把部分背景效应误算成动作效应。随机化 \(a\) 则可以在这个已知系统中隔离动作系数。

还可在背景 c 已观测、线性形式正确、误差独立且动作具有条件变异的假设下，拟合 \(y\sim1+a+c\)。新增独立样本检查中，朴素 OLS 系数为 0.934986，调整 c 后为 0.202325，随机动作样本为 0.202418；真实动作系数仍为 0.2。该新样本使用独立子流，原始 a/c/y 已保存为 CSV，不能与上图旧样本的具体数值混用。

从总体也能手算遗漏变量偏差：

\[ \begin{aligned} &0.2+0.8\frac{\operatorname{Cov}(a,c)}{\operatorname{Var}(a)}\\ &=0.2+0.8/1.09\approx0.933945. \end{aligned} \]

观察到了混杂因素并满足识别假设时，调整本身可以恢复系数；缺少同状态下的动作变化则会使估计病态。

这个例子不意味着所有动作视频数据都必须随机采集，也不证明观测预训练无用。它说明：预测历史动作伴随的未来，与预测在同一状态下改一个动作会怎样，是不同的统计问题。真实机器人还存在状态部分可见、动作支持有限与闭环误差积累。

3.2 实验 C：让预测误差与规划成功分开受检

固定相机、控制模式和轨迹来源，先按场景/轨迹划分数据。预测层测不同 horizon、动作幅度、接触与遮挡下的误差和不确定性；planning 层测相同目标、相同动作预算下的成功率、碰撞/越界和恢复成本。保留无模型控制或已有 policy 基线。

加入三类对照：打乱动作输入，检查模型是否真正使用动作；固定状态改变动作，检查干预预测；保持动作但改变无关背景，检查是否依赖视觉捷径。规划器搜索次数与模型推理时间也要计入预算，不能只比较最终成功而忽略每步搜索成本。

若 latent distance 改善而真实成功不变，需要检查目标表示与任务代价是否对齐；若 planning 只在训练环境好，报告支持集边界。模型生成的视频看起来连贯，不能替代这些控制测试。

3.3 已执行的最小 planning 检查

为使“固定状态改动作”有实际落点，仓库另实现了可精确重置的二维状态模拟器。状态为位置与速度 \(s=(x,v)\)，动作 \(a\in[-1,1]\)，步长 0.1 秒，动力学为：

\[ x_{t+1}=x_t+0.1v_t,\qquad v_{t+1}=v_t+0.1(a_t-0.1v_t). \]

用 4,000 个随机状态—动作转移，通过带截距的最小二乘学习下一状态；另将同一数据中的动作列打乱，拟合诊断对照。测试转移独立生成，共 1,000 条。真实系统本来就是无噪声线性模型，因此正确模型的一步误差接近浮点精度；这是模型族完全匹配的刻意简化。

规划使用 random shooting：每次从同一状态预测 12 步，评价 256 条候选动作序列，其中 21 条为常值序列；每执行一个动作便重新观察。目标代价包含位置误差、速度与动作平方，并加终端代价，系数在脚本里固定。正确模型与打乱动作模型使用相同候选流；另设限幅 PD 控制 \(a=\mathrm{clip}(2(g-x)-2.5v,-1,1)\) 作简单基线。

24 个配对 episode 各运行 80 步，目标交替为 -1/+1，初始状态从独立 seed 生成。成功判据是终点位置误差小于 0.1、速度小于 0.15，且全程位置没有越出 [-2,2]。即使越界也继续模拟以保留诊断轨迹；这里没有实体设备。

正确模型 MPC 与 PD 的平均累计代价分别约 11.81 与 11.89；这点差异不构成 MPC 普遍优越的证据。更有信息的是：同一个规划器与相同搜索预算，在错误动作依赖上产生了严重失败。这个结果只说明在已知线性模拟器中，预测器必须保留可用的动作效应；它没有训练视觉 encoder，也没有检验接触、遮挡和真实机器人泛化。

运行 python labs/planning_probe.py 可重做这项检查。扩展到 V-JEPA 类视觉模型前，应先增加部分可观测、模型误差与环境重置误差，再分别检查动作支持、长 horizon 与规划器利用模型漏洞的程度。不能将该简单系统的 24/24 写成视觉世界模型的成功率。

4. 一项混合模态结果的实际边界

Tables 11–12 的整体结果与 mixed-input 子集须分开读：后者只有 441 个 prompt，数值为 60.4%/47.3%。论文摘要的 60.4% 与 Table 11 的 overall 58.8% 存在口径不一致；此处遵循完整表行。

这组证据支持作者在特定 mixed-modal 生成任务上获得可竞争的偏好评价，但不能把 51.6% 无条件称为统计显著优势，也不能外推成所有视觉问答更强。候选系统的输出能力、展示方式、评判规则和受试样本共同定义了比较。

因此阅读前沿报告时，应先问新能力是否被协议允许出现，再看是否在对等条件下验证。这里的 Gemini+、GPT-4V+ 已经通过先生成 caption、再接 DALL-E 3 的链路提供图像输出。它们与端到端 Chameleon 的比较包含模型、训练和系统链的差异，不能当作裸基线没有图像输出，也不能隔离网络结构的效应。

5. 用证据状态管理研究判断

本次核验的论文都能通过原始全文和独立 DOI 元数据追溯，但“论文存在”不等于每个主张都被验证。这里区分四种记录：原文直接结果；在原文公式上可检查的推导；实际运行的构造实验；尚未执行的实验设计。后三种各有用途，不能冒充第一种。

下一步值得做的研究不是继续增加模型名，而是选择一个失败机制和可控成本：固定视觉预算检验共享训练；用成对图像检查推理后的 grounding；用动作干预验证潜在动力学。选择哪一个取决于能获得哪些数据、算力与环境，不存在脱离条件的统一机会排名。

本章的三个方案尚未在大型模型或机器人上执行；3.3 节已执行的是独立的线性模拟器检查，因此没有“预期提升百分比”。构造实验有完整脚本和输出；论文数字有表/章节和限制；后续新证据可以推翻当前判断，而不需要推翻整张时间线。
