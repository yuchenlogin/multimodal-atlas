# 可直接加入正文的复算说明

以下段落为本次审稿基于已执行算式给出的补充草案；不代表大型模型实验结果。06 的时间坐标仍须先按审稿 M3 修正。

## 03：采样模型数据卡

本实验不读取真实视频。对每个试次抽取 u~Uniform[0,1)，把 u×Delta 解释为事件起点到下一采样位置的距离，再判断它是否小于事件持续时间 delta。这等价于周期采样网格下的随机相位模型；忽略片首片尾，只需命中一帧，检测器完美。F 分别为 8、16、32、64、128、256，同一批 100000 个 u 用于所有 F，所以这些 Monte Carlo 点相互相关。若改成固定片内采样点，并要求事件完全处于片内，边界条件及解析概率也应同时改变。

## 04：完成延迟与排队等待

令块到达时刻为 a_i，开始服务时刻为 b_i=max(f_(i−1),a_i)，完成时刻为 f_i=b_i+s。排队等待是 w_i=b_i−a_i，完成延迟是 d_i=f_i−a_i=w_i+s。图中画的是后者：服务 15ms、到达间隔 20ms 时 w_i=0，但 d_i=15ms；服务 25ms 时，第 200 块 w_i=995ms、d_i=1020ms。该 D/D/1 构造显示固定过载的积累，不包括真实音视频系统中的网络、变服务时间、批处理或丢块。

## 06：动作保持长度也改变离散稳定性

这里策略每隔 H 步读取当前位置，然后把速度 u=K(1−x) 保持 H 步。无扰动时，块边界误差满足 e_(j+1)=(1−K Delta t H)e_j，因此稳定条件为 |1−K Delta t H|<1。K=2、Delta t=0.05 时，H=1/4/16 的乘子为 0.9/0.6/−0.6：前两者单调收敛，第三者会超调、交替纠偏，但振幅衰减。H=20 是不衰减的临界振荡，H>20 才在这个线性模型中发散。这不是“长 chunk 必然不稳定”的定律；改变动力学、反馈增益或执行前缀，边界也会变化。本 toy 保持同一个动作，尚未训练能输出多个不同未来动作的 VLA。

## 10：bootstrap 构造与单位数据卡

输入只是一张人工构造的 2×2 结果表：80 个共同正确、10 个仅 A 正确、20 个仅 B 正确、90 个共同错误。由此构造 200 个 pair 的 d_i∈{−1,0,1}，假设它们是独立 item；每次重采样整个 pair，避免破坏 A/B 的相关关系。没有模型预测文件。点估计为 0.05，即 5 个百分点；4000 次经验 bootstrap 的区间是有限 Monte Carlo 结果，离散分位点附近的微小尾数不应被解释为证据强弱的精确差异。若真实数据含一个视频的多道题，就必须保留 video ID 并整体重采样视频。

## 11：把两个泄漏率写在一起

“一个族横跨训练和测试”与“随机一条测试记录的同族已见于训练”使用不同分母。前者为 1−p^m−(1−p)^m；对后者，已知当前记录在测试中，只有其余 m−1 份可能进入训练，因此为 1−(1−p)^(m−1)。p=0.8、m=2 时两者分别为 32% 与 80%。图的蓝线估计后者；按族切分的零线是根据构造直接给出的参照，并不是一个训练模型的性能结果。

## 12：混杂 OLS 的可手算目标

构造系统的 c、n、epsilon 相互独立，a=c+0.3n，y=0.2a+0.8c+epsilon。只回归 y 对 a 时，总体斜率为 Cov(a,y)/Var(a)=0.2+0.8/1.09≈0.933945；它混入了背景 c 的关联，不能称为动作因果效应。将 a 随机化为与 c 独立后，背景项不再贡献协方差，总体斜率恢复为 0.2。实际有限样本系数约为 0.936760 和 0.200958，二者与各自总体值的微小差异来自抽样噪声。这个横截面构造没有训练预测器，也没有规划 rollout，只用于展示遗漏混杂变量如何改变回归解释。

## 优先扩展 1：相同 2×2 计数、不同独立单位

目的：让第 10 章读者看见“相同五点差值和相同边际分数，为何区间不同”。保持 80/10/20/90 个记录完全相同，但把它们组织成 20 个 cluster，每个 cluster 的 10 条记录具有相同结果：8 个共同正确 cluster、1 个仅 A 正确、2 个仅 B 正确、9 个共同错误。于是共有 200 条记录，却只有 20 个独立 cluster；不是把题数机械除以十，而是显式改变构造的相关结构。

审稿中已独立执行此扩展：对 `[0]*8+[-1]+[1]*2+[0]*9` 使用独立 `default_rng(336)`、4000 次 20-cluster bootstrap，点估计仍为 0.05，95% percentile interval 为 [−0.10,0.20]。这比当前 item bootstrap 宽得多。该数值目前只在审稿中执行，尚未加入作者的实验生成器，不应写成现有图已包含。正式加入时应同时生成 item/cluster 两种重采样结果，并保存 `cluster_id,item_id,score_A,score_B` 及每次 bootstrap draw；与原构造分开写明假设。它不验证任何真实模型的显著性。

## 优先扩展 2：混杂可以通过什么假设消除

第 12 章可增加第三个估计器：在同一观测样本上回归 `y ~ 1 + a + c`。只要 c 已观测、方程线性正确、误差与 a/c 独立且有足够动作变异，调整 OLS 就能识别构造中的动作系数，不必把“必须随机化”作为普遍规则。审稿按现有共享 RNG 的完整消耗顺序重生同一份 10000 条样本，实际拟合得到截距 0.001355、动作系数 0.197778、背景系数 0.803566。这与朴素 OLS 的 0.936760、随机动作 OLS 的 0.200958 形成有解释力的三组比较。

还可以降低动作噪声 0.3，让观测策略几乎确定地跟随 c，展示正值性/共线性问题：即使背景变量已观测，缺少同状态下的动作变化仍会使估计不稳定。必须报告每组的样本量、动作支持、设计矩阵条件数与独立随机重复，不能只挑一个 seed 的漂亮回归系数。

## 优先扩展 3：01 从 loss 数值走到可检查梯度

令 CLIP 单方向目标按 N 个图像平均；在零 logits 时，对 logit 矩阵的梯度为 `(softmax(S)−I)/N`，Frobenius norm 是 `sqrt(N−1)/N`。同样条件下，SigLIP /N 的每对梯度绝对值是 `1/(2N)`，因此完整 N×N 梯度矩阵的 norm 为 1/2。它们的梯度尺度与 loss 数值并不以相同方式随 N 变化，不能由图 2 的纵轴直接选择学习率。

更关键的是共享 bias：零 logits、零 bias 时，SigLIP 对 b 的导数为 `(N−2)/2`；N=64 时为 31，反映负例远多于正例。如果所有相似度先视为零，令 b=−log(N−1)，就把预测正例概率设为 1/N，并使这一个共享 bias 导数为零。审稿已独立核算 N=2/8/64 的梯度 norm 和 bias 导数。正式实验可用中心有限差分验证公式，再加入一对语义相同却被当负例的样本，比较多正例目标如何改变梯度方向。保留 logits、pair labels、解析梯度、有限差分误差；不要把该 toy 的梯度 norm 等同真实编码器参数梯度。

## 优先扩展 4：09 用长度不等的数值反例检验实现

仅画 dL/dDelta 还没有让读者看见长度归一化为什么改变目标。可构造 chosen 为 5 个 token、每 token 的 policy/reference log-ratio 为 0.02；rejected 为 20 个 token、每 token log-ratio 为 0.01。序列求和得到 Delta=0.1−0.2=−0.1；改成各自 token mean 得到 Delta=0.02−0.01=0.01，连符号都改变了。原始 DPO 的序列概率定义对应前者。正式脚本应从合法 token 分布/固定 log-prob 构造计算两种目标，验证 prompt/padding mask 和 EOS 处理，并用有限差分检查 margin 梯度。这个实验不需要训练策略，也不能说明哪种长度偏好在所有用户任务上更好。

## 后续扩展的最小数据契约

所有新教学实验宜按 `probe_id/config_id/replicate_id` 保存：构造类型、独立单位、n、seed/substream、参数、原始观测、聚合值和单位；图表另保存 `figure_id → data_file → generator → source_kind`。逐章独立 RNG，让改 03 的 MC 样本量不再改变 10 的区间。CSV 只是一种可选载体，完整 raw JSON 同样可以；关键是保留分子分母和 pair/cluster/provenance ID，而非为每张图另造一个只有聚合数字的文件。

增添这些有明确反例的实验，优先于再增加一个没有对照的模型介绍。00 可用小矩阵验证 causal/padding mask 与全局 token mean，05 可核对 epsilon/x0/v 的代数互换，08 可比较全矩阵与分块 online softmax 的数值误差和理论中间阵大小；它们应继续叫机制检查，未测 GPU 就不填写速度提升。
