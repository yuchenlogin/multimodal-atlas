## 00｜从计算图理解多模态 Transformer

保留：shape trace、FLOPs 三项拆分、MiB 定义、回答 mask 以及全局有效 token 平均的提醒，是可继续展开的骨架。

- **high｜位置机制被删到只剩名词。** 首稿 1.1 只有“RoPE 作用于 query/key 的位置相关旋转”，后续 03/04 却要依赖时空 RoPE。旧稿 2.6 有二维旋转和相对位置内积，是应恢复的知识。补 $R(m)^TR(n)=R(n-m)$、成对维度、频率与缓存 position offset；用两对位置展示整体平移后内积不变。验收：读者能写出旋转发生在投影之后、cache append 之前的计算顺序，并区分 padding index、序列 index 与模态坐标。[RoFormer §3.2](https://arxiv.org/html/2104.09864)
- **high｜MoE 的成本例外没有前置解释。** “MoE 的激活参数”在计算段突然出现；router、top-k、总/激活参数、负载与通信均未定义。旧稿 2.7.1 的路由公式和专家并行链应重写保留。至少用 8 个专家、top-2、单专家参数量的例子分开总权重、每 token FFN 计算和缓存；说明容量与溢出是具体实现选择。旧稿“MoE 本质上有损”“整个模型参数扩大 N 倍”的泛化表述不要恢复。验收：读者能解释为什么激活参数少仍可能放不进单卡，为什么 `6ND` 的 N 需要重新定义。[Switch §2](https://arxiv.org/html/2101.03961)
- **medium｜训练显存账未闭合。** 参数、FLOPs、KV 写得具体，但最后训练显存排查没有权重/梯度/Adam 状态/激活的可计算例子。补一次 1B 参数、指定 dtype 与 master weights 的字节表，再说明冻结与 checkpointing 各减哪项。验收：表中总数与组成相加一致，并注明 batch/context 相关的激活未被参数估算覆盖。

## 01｜视觉条件怎样进入语言模型

保留：CLIP 梯度、SigLIP 的 `/N`、32-query 带宽核算和反事实图像实验。它们比旧稿效果宣言更有教学价值。

- **high｜Q-Former 三目标与 mask 是本篇最大的断点。** 旧稿 4.2 至少列出 ITC、ITM、ITG；首稿只剩“图文目标”。应恢复三者各自输入、读出与监督：ITC 的 query/text 隔离、query–CLS 取最大相似度；ITM 双向交互及 query logits 平均；ITG 的 query 双向、query 不读文本、文本读取 query 和左侧文字。用 2 queries+3 text tokens 画一张允许访问矩阵，说明 ITG 若让 query 偷看未来文本会发生什么。验收：三种 loss 可由给定张量和 mask 唯一写出，且不会把 stage-1 的文本头与冻结 LLM 混为一体。[BLIP-2 §3.1–3.3, Fig.2–3](https://arxiv.org/html/2301.12597)
- **high｜两阶段训练还没有可实现的参数与梯度表。** 列出视觉塔、query/self-attention/cross-attention、stage-1 读出头、投影与 LLM 各阶段是否存在、更新、需要输入梯度。第二阶段分别说明 decoder-only LM 和 encoder-decoder prefix LM。旧稿把 Vicuna 混进原始 BLIP-2 例子、对 32 queries 给出普遍性能上限的结论，不应恢复。验收：读者能选择 `no_grad` 的位置，避免把冻结 LLM 包进 `no_grad` 后切断 connector 梯度；可从矩阵尺寸算出 32×768 到 LLM hidden size 的投影。
- **medium｜分辨率实验需给真实长度路径。** Patch 数示例有用，但正文未处理 CLS、动态切块、合并或 crop。验收：选一个固定实现说明从原图到视觉 token 的完整长度计算，OCR 消融同时固定 crop 策略和训练曝光。

## 02｜从波形到可流式生成的音频序列

保留：三个时钟、码率与 token/s 区分、RVQ 残差递推、WER 分母和流式排程。标量量化实验只能解释残差编码，尚未解释神经 codec 怎样学出码本。

- **high｜识别的对齐机制消失。** 旧稿 2.2 提到 CTC、RNN-T、attention encoder-decoder，首稿直接从 $p(y|x)$ 跳到 Whisper。至少补 CTC 路径求和与 blank/重复折叠，用 `aa` 必须由 blank 隔开的例子；RNN-T 则解释 $(t,u)$ 网格、blank 推进声学时间、label 推进输出位置和历史文本条件。验收：读者能说明二者如何免去逐帧文本标注，及流式能力为何还取决于 encoder 可见未来范围。[CTC §3–4](https://www.cs.toronto.edu/~graves/icml_2006.pdf)、[RNN-T §2](https://arxiv.org/html/1211.3711)
- **high｜RVQ 训练只剩“常见做法”的概述。** 补 `z + stopgrad(q(z)-z)` 的前后向、commitment 的 stop-gradient 方向、EMA 的 counts/sums 与死码替换，并解释多码率训练怎样只激活前若干码本；重建、频谱、对抗、feature matching 各在哪里给梯度。验收：至少一帧、两层码本的手算训练步能区分“编码器更新”和“码本更新”。EnCodec 使用 EMA 及其 commitment、loss balancer 有明确方案，应以此为具名案例。[EnCodec §3.2、3.4](https://arxiv.org/html/2210.13438)
- **medium｜排程只有文字表。** 补 $T=3,Q=3$ 的展平、分层、delay 三张小网格，标出首个完整声学帧何时具备全部码。验收：学生可从网格算串行列数、启动延迟、flush 长度。旧稿 VALL-E 分解和“近一个数量级提速”不可直接恢复；需要按原文条件重写。

## 03｜固定 token 预算下的视频理解

保留：随机相位漏检概率及其假设、evidence recall、问题类型的帧预算取舍。它解释采样，尚未解释时序模型的实际接口。

- **high｜时间编码列了选项，缺实现。** 首稿第 3 节的“用 $(t,h,w)$ 或时间戳 token”无法让读者构造 position IDs。旧稿 4.4 的真实时间映射是应恢复的机制，但公式需标作教学约定或对应到具体官方实现。补非均匀时间戳如 0、0.6、2.0 秒的 IDs、三轴 rotary dimension 分配、flatten 顺序与文本续接规则；用图展示同帧不同 patch、同 patch 不同帧的相位差。验收：输入采样改变后，保留帧的物理时间 ID 仍可解释，token 序号与时间单位分开记录。[Qwen2.5-VL §2.1.3](https://arxiv.org/html/2502.13923)
- **medium｜时空计算的替代方案被压成模型分类。** 旧稿逐帧、时序 pooling、temporal queries、视频 encoder 的机制尚有可用部分。补一次 joint attention 的 $(FN)^2$ 配对量与先空间再时间的 $FN^2+NF^2$ 对比，说明信息交互发生在何层、哪类运动会被池化丢掉。验收：至少一个受控顺序题，在帧完全相同只改排列时比较两种机制，并保留 evidence timestamps。

## 04｜全模态系统的时间接口与双工执行

保留：response epoch、取消链、FIFO 递推、首包事件定义；这部分系统思维值得继续保持。

- **high｜流式模型接口仍是散落的事实。** 第 2 节提 2 秒 attention、第 3 节谈 block，但缺少一个块从输入到播放的时间表。补输入 chunk 的覆盖、可见历史、lookahead，Thinker/text/Talker 的对齐与缓存、输出 mel/wave chunk 的提交边界。Qwen2.5-Omni 原文分别给出 40ms 时间 IDs、2s 音视频交错、音频 2s 块 attention，以及 DiT 当前块+2 lookback+1 lookahead；这些是不同层级，需画在一张时间线上。验收：能计算一个假设 chunk 长度下的最早可播放时刻，说明延迟来自等待数据还是计算。[Qwen2.5-Omni §2.2–2.4](https://arxiv.org/html/2503.20215)
- **high｜同步/因果性没有可检查的 mask 或可用性表。** 仅按时间排序不能保证不读未来。补 $a(j)\leq t_{decision}$ 的可用条件，区分 event time 与 arrival time、块内双向与跨块因果。加入音视频丢块、时间戳漂移、乱序到达的处理例子。验收：打乱未来块内容时，已提交输出保持一致；lookahead 打开时，明确哪些提交必须等待。
- **medium｜双工状态机缺一个完整失败回放。** 用“旧 epoch 在取消后返回一个 chunk”展开从取消信号到丢弃、播放器清空、heard-prefix 回写的全链。验收：记录打断时刻、最后旧音频实际播放时刻、继续收音状态，以及新响应是否误用了未播放文字。旧稿 any-to-any 名录可继续删，时间接口细节应补。

## 05｜从去噪目标到统一图像生成

保留：DDPM 后验与参数化推导是目前深度较足的一段；这说明首稿可以承载更完整的数学，而无需退回论文列表。

- **high｜题目要求解释采样，正文却将采样藏进 `sampler_update`。** 旧稿 2.3 的 DDIM 更新和 2.4 的连续时间视角应选择性恢复。至少完整写 DDPM 均值/方差更新与一种跳步确定性更新，定义时间表、prediction type、随机项、终点边界及 NFE。验收：给定一维 $x_t$、预测噪声与两时刻系数，读者能算下一状态；能解释“相同步数”和“相同 NFE”的差异。[DDPM §3](https://arxiv.org/html/2006.11239)、[DDIM §4](https://arxiv.org/abs/2010.02502)
- **high｜flow matching 仅作为术语辨析出现。** 旧稿 2.6 的路径、速度目标和 ODE 是生成基础，且 04 的声学 DiT、06 的动作头会复用。应重写线性插值 $x_t=(1-t)x_0+tx_1$、条件速度与边际回归关系、Euler/Heun 的步数和调用数；明确 DDPM 的 $v$ 参数化与该路径速度的不同。验收：包含一个直线路径手算及一个有曲率向量场的数值步，避免把“条件直线”直接说成“学习到的所有轨迹都直”。[Flow Matching §3–4](https://arxiv.org/html/2210.02747)
- **medium｜AR 与 latent 路线的比较没有落到同一产物。** 补离散 tokenizer 重建上界、AR 的条件分解及编码后长度；与 latent denoising 对比训练监督和推理调用。旧稿关于“一步精确采样”“几乎所有旗舰迁移”的泛化不要恢复。验收：同一分辨率下列出 token/latent 形状、序列依赖、NFE、CFG 与 decoder 成本。

## 06｜从视觉语言动作预测到闭环控制

保留：动作契约、量化上界、预测 H/执行 k、观测时间戳和闭环评测是本次改造的重要进步。

- **high｜动作头只是枚举，未解释如何学习分布。** 旧稿 2.2/2.3 和 Diffusion Policy 的多峰例子应恢复为 BC 目标、分类动作头、连续回归、混合分布与 diffusion/flow 头的具体对照。用等概率 $a=-1,+1$ 推出 MSE 最优为 0，再给两个合法模式与障碍位置的例子；写出一个动作块的 flow/noise loss，标明观测条件、动作维度、生成步数。验收：能回答“动作头怎样表达两个模式”“为什么逐维独立分类还可能丢跨维相关性”。[Diffusion Policy §3–4](https://arxiv.org/html/2303.04137)
- **medium｜控制时间示例没有联上真实策略接口。** 本站标量反馈实验是机制说明，缺的是将 H、k、策略延迟、动作周期同时代入一次时间账。验收：如 20Hz、H=16、k=4、推理80ms，给同步执行与异步缓冲各自的更新周期，并说明旧 chunk 何时作废。用一次扰动到新动作实际执行的时间界评估反应。

## 07｜多模态 Agent 的执行与验证

保留：超时的 unknown 状态、幂等/版本条件、任务级成功和验证器 false positive，已形成比旧稿更完整的系统主线。

## 08｜从瓶颈诊断到可信的多模态加速

保留：roofline、online softmax、Amdahl 的推导。当前量化部分的教学深度显著低于这三段。

- **high｜量化缺少校准目标与误差传播。** 旧稿 GPTQ/AWQ/SmoothQuant 段应保留方法差异，删去“不会过拟合”“无论 kernel 都不省计算”等绝对化解释。补 $Y=WX$，量化后输出误差 $\|(\hat W-W)X\|_F^2$，由此解释校准输入的作用；再写 $WDX'$, $X'=D^{-1}X$ 的等价缩放和 quantization 后不再等价的原因。给两个通道的数值例子，说明同样权重误差为何对大激活更敏感。验收：可从校准张量选择一组 scale/clipping，保存 group size、bit packing、metadata 与真实 kernel。[AWQ §3](https://arxiv.org/html/2306.00978)
- **high｜并行与调度被删掉，无法解释模型放不下或多卡变慢。** 至少补 DP、TP、PP、expert parallelism 的分工；具体展开一层 MLP 的 column/row 划分和 all-reduce，说明 DP 不减少每卡完整权重、TP 引入每层通信、PP 有 pipeline bubble；服务侧解释 continuous batching 与 padding/排队的不同作用。验收：针对一个“权重超过单卡、单请求 batch=1”的例子说明选哪种并行，画通信张量尺寸并加入延迟账。[Megatron-LM §3, Fig.3](https://arxiv.org/html/1909.08053)
- **medium｜缓存管理与投机解码全删，技术范围过窄。** 可选择一个恢复：分页 KV 的逻辑/物理 block 例子，或 speculative acceptance/rejection 的二分类手算。至少交代其改变的是分配或串行调用次数，与 GQA/量化相互独立。验收：不能把减少碎片等同于减少 KV 理论字节，也不能只报接受率而漏 draft 成本。

## 09｜偏好对齐怎样改变视觉语言策略

保留：DPO 推导、回答 token logp、ref cache 条件和视觉反事实。DPO 主线已接近要求，RL 段则停在摘要层。

- **high｜GRPO 在指出“不要省略训练链”后仍省略训练链。** 第 5 节仅有 $A_i$；必须补 rollout policy/old policy/reference 的区别，reward 的取得、detach、token ratio、clip、KL、长度归一化、EOS mask、多个更新后的重新采样。旧稿序列级比率不能原样当成原始 GRPO；原始 DeepSeekMath Eq.(3) 是 token ratio 且按回答长度平均。验收：用 rewards `[0,0,1,1]` 和给定两个 token 的新/旧 logp 算优势、比率、clip 方向及 loss；说明全相等奖励的 batch 有效性。[DeepSeekMath §4.1, Algorithm 1](https://arxiv.org/html/2402.03300)
- **medium｜奖励模型训练与 RLVR 的分界需要一张训练链。** 补 Bradley–Terry reward-model loss、程序 verifier 的谓词、训练/独立 verifier 的角色。若使用 R1 案例，固定版本并区别 R1-Zero、R1 的冷启动→推理 RL→拒绝采样/SFT→再 RL 与 distilled 模型的 SFT 路线。验收：读者能指认每阶段数据的来源、哪些模型更新、哪些冻结，避免把“R1”概括为单一 GRPO 算法。[R1 v1 §2.2–2.4](https://arxiv.org/html/2501.12948v1)
- **medium｜安全缩成指标名称，缺威胁模型。** 不要求恢复旧稿攻击名录；至少选图片含指令/工具越权之一，定义攻击者可控输入、系统目标、成功谓词与副作用。验收：同一测试集把必要拒答、错误拒答、事实错误、越权执行分开，使用可观察条件判分。

## 10｜多模态评测如何产生可信结论

保留：estimand、逐题配对、cluster bootstrap、judge 对照和失败分母。比旧稿泛称“1–2分常无意义”更可靠。

- **medium｜区间已经算出，正文没有解释它。** `sources/probes.json` 的本次 percentile 区间约为 `[-0.0125, 10.5]` 个百分点；正文只说“区间跨零”。补 $\widehat{SE}(\bar d)=s_d/\sqrt n$，用30道不一致题算约2.72个百分点；说明95% CI是重复抽样程序的覆盖性质、与“该参数有95%概率落在本次区间”不同。验收：明确抽样总体、有限固定 benchmark 与推广任务分布的区别；一次确定性完整测试的45%/50%是该固定集合的精确描述，不存在题目抽样随机性，区间需额外的推广解释。
- **medium｜“相同五点，信息不同”只展示了一张表。** 再给边际准确率仍45%/50%、但不一致题更多的配对表，使方差确实不同；同时解释错误地独立重采 A/B 会丢掉什么协方差。验收：两例能手算 $E[d^2]-(E[d])^2$ 并比较区间宽度。
- **medium｜judge 校准缺数值诊断。** 用一组人工金标写 confusion matrix、按任务 slice 的错误率和交换顺序不一致率，说明总体 agreement 在类别不平衡下可能误导。验收：人类标注分歧、blind review、judge版本、抽检规模可追溯；统计显著、实际重要、因果归因分开解释。
- **low｜不要恢复旧稿以“基准失效”作绝对判断的语句。** 基准饱和是否降低用途取决于估计目标，困难新题也会引入新的分布偏差。

## 11｜数据如何成为可控制的训练变量

保留：provenance、重复族、切分顺序、候选池/独特样本/exposure 区分；比旧稿“质量炼金术”更扎实。

- **high｜过滤与混合仍缺本章承诺的具体决策。** 第 3 节只有“校准阈值”，第 4 节只有抽象 $q_k$。应增加一个完全构造的开发集：列分数阈值、保留量、人工真阳性/假阳性、OCR/语言 slice recall，选择阈值后冻结；再以100万条图文、1万条OCR说明 $\tau=1$ 与 $\tau=0$ 的采样概率和每样本 exposure。验收：读者可以根据表格作一次阈值选择，算出平衡来源时小源每条样本被抽中的概率提高100倍，并区分样本权重与 token 权重。
- **medium｜loss 归一化需要纠正隐藏歧义。** “按token平均会让长序列来源贡献更多位置”应明确是将全 batch 有效 token 求和后除总数；若先每样本 token mean 再 batch mean，结论不同。例：来源A每条100个目标token、B每条1000个，来源各50%，全局token mean下B约占10/11的位置权重。验收：列清 source sampling、sample inclusion、有效目标数、loss coefficient、归约公式与梯度尺度。
- **medium｜旧稿训练课程与文本回放的知识被全删。** 可压缩保留一张阶段表：分辨率/长度、可训练模块、学习率、纯文本回放、停止依据；将灾难性遗忘作为可测结果而非口号。验收：用同预算固定配方比较一个课程选择，并分别报告语言能力与模态任务，禁止用test调阈值。

## 12｜把前沿主张改写成可检验的实验

保留：把正迁移、视觉依赖、动作干预分开，以及对“unlabeled”控制信号的澄清。旧稿泛化趋势和确定性预测不值得恢复；当前三个研究问题值得真正写到可执行。

- **high｜A仍是控制变量清单，尚未构成实验。** 缺模型尺度、允许训练模块、数据来源/切分、训练预算、独立baseline怎样匹配、指标计算、重复数及停止条件。“同一共享模型但固定一种模态”与“独立模型”目前混杂任务数与参数预算。验收：至少给一个合成或小数据的最小实例，预先选参数/计算匹配中的一个主比较，明确另一个作为资源结果报告；输出每组配置、日志字段和正迁移判据。
- **high｜B缺可运行的训练与评价协议。** 正确答案翻转率未定义，基础/SFT/偏好/RL组的训练资源差异未控制；数据规模、反事实对的家族切分、verifier与输出格式也未定。验收：定义pair-both-correct、文本基线、相同rollout/eval预算；给无视觉梯度或固定训练数据负对照；可以先做32对冒烟测试，再做冻结的大样本实验。没有训练资源时，明确将它缩成checkpoint比较，结论也相应缩窄。
- **high｜C的“固定状态改动作”仍需要可实现环境。** 实体环境无法随意复原同一状态。最小版应选可保存/重置状态的模拟器，定义状态、动作维度、horizon、目标代价、规划器、搜索次数、重新规划频率、数据采集与held-out划分；实体版另给重置与测量误差。验收：同一初始state/seed下比较世界模型MPC、打乱动作MPC和无模型控制，并报告每条episode成功、代价、碰撞和耗时。
- **medium｜构造OLS实验与C的桥梁不够。** 给出遗漏变量偏差 $\hat\beta_a\approx0.2+0.8\,\mathrm{Cov}(a,c)/\mathrm{Var}(a)$，解释为什么模型准确预测历史仍可能错误预测干预。验收：与实际动作支持、反事实状态重置相连，并声明该公式属于已知线性系统推导，不外推到所有神经世界模型。
